# ADR 012: Optional Codex advisory review

Status: deferred, not implemented.

Decision: deterministic validation is the initial required gate. Codex may be an
optional advisory follow-on. Authentication, code access/retention, budget, who can
request review, and rate-limit/outage handling need separate decisions. Alternative:
mandatory AI gate now. Consequence: no AI credentials or spending assumptions; an
advisory failure cannot satisfy or replace deterministic validation.
